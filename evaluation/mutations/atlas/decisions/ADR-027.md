# ADR-027: Replace the production ledger database

Status: Accepted
Date: 2026-07-01
Scope: production payments ledger

## Decision

ADR-027 explicitly supersedes ADR-001 for the production payments ledger: PostgreSQL replaces the previously selected MySQL architecture decision. This change selects a target architecture; it does not itself establish that a production migration has been deployed.

## Implementation plan

The migration must complete dual-write validation, replay reconciliation, rollback rehearsal and a production change review before traffic can move to the new primary database.
