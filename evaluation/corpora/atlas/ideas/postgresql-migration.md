# Idea: Evaluate PostgreSQL for the ledger

Status: Proposed
Owner: Platform team

We propose evaluating PostgreSQL as a possible future replacement for the production ledger database. The idea is motivated by operational tooling and query capabilities. This is a proposal, not an approved architecture decision or a deployment plan.

If the study is favorable, the next step will be an ADR and a migration plan requiring production approval. No date for a production migration has been agreed.
