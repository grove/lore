# INC-014 — Reported duplicate refund after timeout

**Status: Closed incident report.** **Classification: Reported outcome, not independently verified by Lore.**

The incident report says a developer retried a legacy refund after an ambiguous provider timeout. The legacy provider did not deduplicate the second write, and the report describes a duplicate refund.

The follow-up procedure recommends read-only reconciliation of ambiguous refund outcomes before any additional write. The report does not establish that the current implementation was inspected, that production was verified or that ADR-001 changed.

**Lesson candidate:** Keep historical reports separate from accepted rules and current code observations. See [the runbook](runbook.md) for the current documented procedure.
